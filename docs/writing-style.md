# 青山镇 · 统一行文风格指南

> 本文档是《单挑》所有叙事文本（主线、支线、事件节点、角色背景、设定文档）的**唯一写作规范**。
> 任何人/任何 AI 在编写或修改叙事文本之前，**必须先读本文档**，并同时参考：
> - `docs/background/town-settings.md` — 青山镇地理、门派、家族、时代
> - `docs/background/character-relations.md` — 角色关联矩阵
> - `docs/stories/main-story.md` — 主线基调与终局文案
> - 对应故事线的 `docs/stories/view-stories/*.md`

---

## 一、基调：克制、白描、留白

> **水平基线：拒绝小白文，向猫腻（《庆余年》《将夜》）看齐。** 写不出猫腻的水平，至少别写小白文。

**小白文特征（一律禁止）**：
- 口水注水——一句能说清的事绕三句（"他不由分说地、毫不犹豫地冲了上去"）。
- 爽文金手指腔——主角永远正确、敌人永远降智（"他冷笑一声，一掌拍出，对方顿时口吐鲜血"）。
- 无意义内心 OS——反复"他心想""他暗暗发誓""他的眼神变得坚定"。
- 夸张堆砌——感叹号连发、形容词叠罗汉（"无比强大、极其神秘、令人震撼"）。
- 过度解释——把潜台词说出来（不写"这话里藏着深意"，要写话本身）。
- 巧合硬凑——为推进剧情生造巧合。
- 网络流行语/烂梗（yyds、破防、格局打开）。neta 可以有，但用典要雅。
- 人物工具化——配角只为主角服务，没有自己的欲望。

**猫腻式追求（写作时逐条对照）**：
- 人物立得住：一个动作、一句对话立起一个人，不贴标签。
- 对话有潜台词：说的不是想的，读者能读出第二层。
- 细节有质感：生活化的物件、气味、习惯——世界是"住"出来的，不是"说"出来的。
- 情感克制：悲剧不嚎啕，写"他把礼物扔进了巷子尽头的垃圾桶"。
- 节奏有呼吸：紧张之后给一口闲笔，闲笔里埋钩子。
- 金句点到为止：不喊口号，一句话收尾，让读者自己回味。
- 幽默藏反讽：冷笑话藏在正经叙述里，不抖机灵。

这个世界是赛博朋克与古风修炼的混搭，但叙事**从不解释设定**。义体、炁、灵核芯片都像空气一样存在，角色不会停下来给你讲设定——他们只会用。

**写法**：短句为主，白描动作与物件，让读者自己品出味道。少用形容词，尤其禁用"强大的""神秘的""令人惊叹的"这类空词。悬念靠留白，不靠反问句。

正例（摘自主线）：

> 街边的诊所和眼镜店一样多，换一条手臂和配一副隐形眼镜差不多快。全息广告牌在城市上空轮流播放，内容每天换，但看起来都差不多。

反例：

> 青山镇是一座神秘而强大的修炼圣地，这里的居民掌握着令人惊叹的古老力量，空气中弥漫着令人敬畏的气息。

**规则**：
- 一个句子里只讲一件事。
- 能用一个词说清的，不用两个。
- 科技物件用白描（"换一条手臂和配一副隐形眼镜差不多快"），不写"赛博科技感"。
- 情感不外露。角色难过时写他"把礼物扔进了巷子尽头的垃圾桶"，不写"他感到无比悲伤"。

## 三、对话格式

- 中文全角引号：`「」`。
- 说话人的动作**先于**台词，台词后不重复说明。
- 内心独白不加引号。
- 对话要短，一个人一句话内说完。长对话拆成几段，中间插入动作或环境。

正例：

> 他沉默了很久。然后他说：
>
> 「我们都被骗了。你没发现吗？一点意义都没有。」
>
> 你愣住了。

反例：

> "其实你根本不需要杀他，手刃血亲只是玄门为了更好地拿捏后代编出来的说辞，我知道了这秘密才离开的，所以你要理解我，再见！"他说道。

---

## 四、时间锚点

每个事件的开头，尽量给出一个锚——年龄、年份、季节，或一件具体的事。读者需要知道自己站在哪一段人生里。

正例：
- 「六岁那年，父亲将你叫到祖祠前。」
- 「2074 年，一切都和往年一样，安静地运转着。」
- 「斗炁大会开幕的前夜。」

---

## 五、节点文本结构（游戏内事件）

每个节点 2–4 段，按以下顺序：

1. **场景白描**（1–2 句）：至少带一个五感细节（声音/光/气味/触感）。
2. **推进**（1–3 句）：事件发生，或人物对话。
3. **收尾**（1 句）：转折或留白，不点破，不给结论。

**长度上限**：
- 普通事件节点：正文 ≤ 150 字。
- 关键剧情/战斗/Boss 节点：可放宽至 300 字。
- 选项文案：动词开头，8 字以内（"迎战""收下""去天工坊看看"）。

**战斗轮**：敌人出场前给一句"你为什么必须打"的交代；战斗结果不在文案里剧透（由引擎结算显示）。

## 五·五、选项卡文案（选项 label + description）

玩家在 3 选 1 池节点看到的选项卡，是**事件名 + 事件描述**。这里有一组专属规矩：

- **label = 动词行动句**，不是事件标题、不是剧透。写玩家要"去做什么"，不写"会发生什么"。
  - 正例：「去酒吧喝酒」「观摩归海楼研讨会」「去天工坊看看」「去医馆治疗」。
  - 反例：「九朵桃花酒吧杀人事件」（这是事件标题，不是玩家动作）。
- **description = 一句氛围/去处描述**，8–20 字，白描不剧透。
  - 正例：「杏花街的九朵桃花，晚上最热闹。」「归海楼广发英雄帖，各派齐聚。」
  - 反例：「这里会发生一场命案」「你将在比武中获胜」。
- 引擎会自动在 description 末尾追加「（将进行战斗 · +修炼点）」等标记——写 description 时不要重复战斗/奖励信息。
- 事件的故事名（如「九朵桃花酒吧杀人事件」「回忆中的回忆」）用于事件标题/目录/流程地图，**不直接充当选项卡 label**。

## 六、专名与术语

| 规则 | 示例 |
| :--- | :--- |
| 门派/家族/场所用原名 | 玄门、玄青宗、归海楼、天工坊、九朵桃花酒吧、宝字堂、斗炁图书馆 |
| 组织黑话带引号 | "组织"、"东西"、钟声 |
| 功法/招式名可加粗 | **凝炁诀**、**独臂** |
| 数字用阿拉伯数字 | 2074 年、六岁（中文年龄用汉字）、+4 修炼点 |
| 禁止 | 网络梗、颜文字、emoji/表情符号、叠词堆砌、玄幻腔（"灵气逼人""血脉觉醒"） |

## 七、正/反例对照速查

| 维度 | 正例 | 反例 |
| :--- | :--- | :--- |
| 情感 | 他把礼物扔进了巷子尽头的垃圾桶。 | 他感到无比伤心和绝望。 |
| 悬念 | 知道的人没有机会说，不知道的人也不会问。 | 这座小镇隐藏着惊天大秘密！ |
| 战斗 | 她没有躲，也没有逃。她看见你手中的兵器，轻轻笑了笑。 | 她施展出强大的招式，向你发动了猛烈的攻击。 |
| 科技 | 换一条手臂和配一副隐形眼镜差不多快。 | 高科技义体技术已经极其发达。 |
| 对话 | 他看了你一眼：「去问你父亲吧。」然后他转身走了。 | 他说了很多重要的话，然后就离开了。 |

## 八、AI 写作工作流（给后续补写的指令模板）

用 AI 补写事件/角色文本时，把下面这段（或类似）作为注入上下文，把 `<任务描述>` 替换成具体任务：

```
你是一名文字作者，为肉鸽单挑游戏《单挑》的青山镇世界观撰写叙事文本。
写作前必读：
1. docs/writing-style.md（行文风格，本文件）
2. docs/background/town-settings.md（世界观）
3. docs/background/character-relations.md（角色关联）
4. 相关故事线文档 docs/stories/view-stories/<线>.md（剧情与节点表）

任务：<任务描述>

要求：
- 严格遵守 docs/writing-style.md 的所有规则（白描、短句、「」对话、时间锚点、节点结构）。
- 产出格式：每个节点给 id/标题/正文/选项，正文 ≤150 字（关键节点 ≤300 字）。
- 不新增世界观设定；需要新增时必须标注「[待确认]」。
- 不与角色关联矩阵冲突。
```

## 九、验收清单（写作完成后自查）

- [ ] 全文白描，无空形容词、无玄幻腔、无网络梗
- [ ] 每段正文 ≤150 字（关键节点 ≤300 字）
- [ ] 对话全部用「」且短句
- [ ] 开头有时间锚点
- [ ] 视角统一（事件=你，设定=他/她）
- [ ] 未破坏任何既有设定（角色、组织、"东西"、钟声）
