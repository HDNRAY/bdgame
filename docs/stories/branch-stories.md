# 支线事件（编年史事件）

> 关联文档：`docs/character-relations.md` — 角色关联与支线角色表 | `docs/story.md` — 主线故事与流程 | `docs/town-settings.md` — 青山镇设定

---

游戏没有传统的主线/支线之分，而是由一系列**编年史事件**构成。每次开局随机选择该轮经历哪些事件，每个事件可能关联特定角色、奖励、或剧情分支。

## 流程架构：一切皆事件 + 一切皆 flag（渐进生成）

地图不再"选完故事一次性锁定"，而是 **33 个节点槽 = 候选声明，到达时按当前 flags 现场解析**：

```
EventDef.placement → buildNodeSpecs() → NodeSpec[33]
进入节点 → resolveNode(spec, flags)：
  过滤 when → 非 fallback 候选优先（故事专属压过通用池）
  → 恰好 1 个直接开始；多个加权抽 ≤3 → 玩家 3 选 1；否则用 fallback 池
```

- **条件**：json-logic-engine 表达式（`when`，只读求值，如 `{"==":[{"var":"flags.story"},"sect"]}`）
- **写入**：自研 Effect DSL（`set` / `setMany` / `add` / `grant` / `points` / `heal`），用于 `EventDef.effects` 与 `Choice.effects`，无函数钩子
- **奖励**：`RewardSpec`（`points` / `item`+标签过滤 / `fixed` 固定几个 / `none` / `heal`）；修炼点动态配额走 `flags['points_granted']`
- **链式解锁**（喝酒结拜 / 副手天工坊）：前一个事件 `effects` 写 flag，后一个事件 `placement.when` 读 flag——没得酒，后一个事件永远不会出现
- **战斗可插拔**：任何 `Round` 可加 `enemyId`（固定）或 `enemyPool`（随机池）
- 竞技数据（`tournamentData`）保持独立纯函数，仅在边界用 flag 对接（决赛 Boss、淘汰结果）

关键文件：`src/game/entities/{condition,effect,reward-spec,node-spec,event,round,story}.ts`（数据模型）、`src/game/roguelite/{map-builder,engine,util}.ts`（解析与引擎）、`src/data/events/`（全部事件，含 placement）。

## n1 · 出身选择（你从哪里来）

n1 是出身选择：从随机 3 个故事线里挑一个。**每条故事线在 StoryDef 里声明 `originEventId`（出身事件）与 `reward`（开局奖励效果）**：

- 选项文案 = 出身事件的 `name`（场景化短句，不用故事线名），如「你出自玄门」
- 展开叙事 = 出身事件的 `description` + `rounds`（白描出身场景）
- 选中后流程：选项的 `effects` 激活故事 flag（`setMany({story, tournament_final_boss, ...})`）+ 发开局奖励 → 进入出身事件 → n2
- **扩展 n1**：给某个出身事件加轮次/选项即可；新增故事线 = 新出身事件 + StoryDef 声明

出身事件定义在 `src/data/events/origins.ts`；开局奖励效果在 `src/data/stories/*.ts` 的 `reward`。

### 1. 归海楼比武大会

| 字段         | 内容                  |
| :----------- | :-------------------- |
| **事件 ID**  | `chronicle_guihailou` |
| **地点**     | 归海楼                |
| **节点数**   | 3                     |
| **奖励类型** | 招式（action）        |

玄门及其他门派前往归海楼切磋交流。**军师**与**博士**以"观摩"为名陪同前往，实为收集实战数据，用于研发战斗芯片。

#### 流程

1. **抵达归海楼** — 归海楼山门前人声鼎沸。你递上请帖，小厮领你入座。台上桑原正在与人切磋，刀光剑影。观众席一角，两个身着斗篷的人正在低声交谈——后来你才听说，那是军师和博士，以"观摩"为名收集战斗数据。
2. **观战切磋** — 几轮切磋下来，你对各家路数有了新的理解。归海楼掌门一刀亲自下场与一位老道表演，剑气纵横，满座喝彩。
3. **收获** — 有所感悟，获得奖励。

#### 关联

- **角色**：桑原（归海楼弟子）、一刀（归海楼掌门）、腊月（表演赛）、军师、博士
- **故事线**：`sect`（n14 切磋、n15 表演赛）、`xuanmen`（n15 重逢小树）

### 3. 九朵桃花酒吧杀人事件

| 字段         | 内容                    |
| :----------- | :---------------------- |
| **事件 ID**  | `chronicle_bar_killing` |
| **地点**     | 九朵桃花酒吧（杏花街）  |
| **节点数**   | 2                       |
| **奖励类型** | 修炼点（points）        |

#### 背景

**九朵桃花酒吧**——开在杏花街上，街对面就是**宝字堂药铺**（飞虎·竹子坐堂行医之处）。名义上老板常年在外，由"女儿"陶朵看店，实则幕后老板是副会长，酒吧是组织的情报据点。

竹子泡的跌打酒在街坊里有些名气，陶朵在他那儿拿货放在吧台后面卖，每隔几天竹子送一次货，顺便收回空瓶。

**唐柔**是唐门旁支，十八岁才得自由身。出来后想学正经医术，在宝字堂已经待了一阵子——竹子教她认药、辨症、处理伤口。她日常就是看店、碾药、跟诊。

| 角色          | 身份                                          | 关联                                                 |
| :------------ | :-------------------------------------------- | :--------------------------------------------------- |
| **陶朵**      | 酒吧"老板女儿"                                | 实际为组织成员。酒吧幕后老板为副会长，是组织情报据点 |
| **酒鬼·无志** | 隐世高人                                      | 常客。在酒吧触发打抱不平→结拜事件的前置              |
| **来风**      | 江湖散人                                      | 常客。打抱不平被随机一组人看到后→喝酒结拜            |
| **风似水**    | —                                             | 常客。结拜组成员                                     |
| **宁浩然**    | —                                             | 常客。结拜组成员                                     |
| **小树**      | 玄门旁支·已出走                               | 常客。结拜组成员                                     |
| **飞虎·竹子** | 宝字堂药铺老板兼医师 / 特殊事件调查科兼职法医 | 街对面宝字堂药铺。定期送跌打酒到酒吧，与陶朵对账     |

#### 事发现场

军方卧底被陶朵**约到后院**，以**毒杀**方式清除。方烈在门口**望风**。尸体伪装成暴毙模样。

唐柔在柜台后面碾药，竹子从后院出来，抱了一箱新泡好的跌打酒，说了句"走，送货"。唐柔放下药臼跟出去。过街进九朵桃花，竹子把箱子搁吧台上跟陶朵对账。唐柔站在旁边打量店里的陈设。

此时事发。陶朵在后院完成了清除。

竹子放下账本走过去蹲下，翻了翻伤口，没说话。过了几秒，头也没回地说了句："去，把我柜子里第三格那瓶药酒拿来。"唐柔转身跑了出去。

#### 各线视角

| 故事线                  | 视角                 | 细节                                                                                                                                     |
| :---------------------- | :------------------- | :--------------------------------------------------------------------------------------------------------------------------------------- |
| **奇遇流（叶寻）**      | **全程目击**         | 准备了礼物想给陶朵惊喜，从后门潜入——轻功极好，未被任何人发现。目睹了后院发生的一切                                                       |
| **军旅退伍（陆斐）**    | 事后得知             | 老柴已查出组织与 2074 年林家灭门有关的间接证据，准备上报时被灭口。李雪影后来告知陆斐                                                     |
| **血海深仇（林晚风）**  | **现场勘查（~n14）** | 以特殊事件调查科身份到场。奇岚已先到。在尸体衣物夹层中发现一叠被烧过的纸屑残片——勉强拼出"2074"、半个"木"字偏旁、以及"义"和"火"等零散字迹 |
| **天生道种 / 玄门子弟** | 听闻传闻             | 在街上听说九朵桃花出了事，不知细节                                                                                                       |

#### 流程

1. **传闻** — 你在街上听说九朵桃花酒吧昨晚出了事。有人被杀，凶手消失得无影无踪。酒吧照常营业，但吧台后面那排药酒瓶少了几瓶。
2. **线索** — 街坊们议论纷纷，但没有人说得清真相。你只打听到死者是个外来人，平时不怎么露面。据说陶朵那晚在店里，但第二天照常开门，像什么都没发生过。

#### 关联

- **角色**：陶朵（行凶）、方烈（望风）、军方卧底（死者）、副会长（幕后）、飞虎·竹子（验伤）、唐柔（目击）、奇岚（勘查）
- **故事线**：`wanderer`（主线目击）、`veteran`（李雪影告知）、`feud`（现场勘查）

### 4. 喝酒结拜学酒功（两段式链）

| 字段         | 内容                                            |
| :----------- | :---------------------------------------------- |
| **事件 ID**  | `chronicle_tavern_encounter` → `chronicle_sworn_brothers` |
| **地点**     | 九朵桃花酒吧（第一阶段池事件）                   |
| **节点数**   | 1 + 1                                           |
| **奖励类型** | 被动（passive）— 酒系功法（`jiu` tag）           |

#### 链式门控（flag）

- **第一段 · 酒馆偶遇**（`chronicle_tavern_encounter`）：3 选 1 里碰到**来风**或**酒鬼·无志** → `effects` 写 `got_wine`；自顾自喝则不得酒。
- **第二段 · 喝酒结拜**（`chronicle_sworn_brothers`）：`placement.when: got_wine`——**没得酒，这个事件永远不会出现**；得酒后，后续第一阶段节点它才进入候选池。

#### 流程

1. **酒馆偶遇** — 你在九朵桃花酒吧独酌，门口进来一个人……（碰到来风 / 酒鬼得酒）
2. **喝酒结拜** — 大家喝到兴起，轮番表演轻功助兴。你也露了一手，赢得一片叫好。最后几个人醉醺醺地拜了把子，约好以后有难同当。
3. **结拜之礼** — 获得酒系功法。

#### 关联角色

酒鬼、来风、风似水、宁浩然、小树

### 7. 漱玉峰瀑布顿悟

| 字段         | 内容                     |
| :----------- | :----------------------- |
| **事件 ID**  | `waterfall_epiphany`     |
| **地点**     | 青山 · 漱玉峰（偏南小峰） |
| **节点数**   | 1                        |
| **奖励类型** | 招式（action）— 4AP/5AP 绝技 |

#### 背景

漱玉峰是青山偏南的一座小峰，峰腰悬着一道瀑布，常年水雾弥漫、水声轰鸣。传说曾有人在瀑布下观水悟出绝技——水势无常，顺势者得之。

#### 流程

1. **上山** — 你沿着山溪一路向上，水声由远及近，最后变成整座山都在轰鸣。漱玉峰的瀑布到了。
2. **瀑布下观水** — 你在瀑布下盘坐。水势千万年不变，又每一刻都不同。你盯着那一道水幕，渐渐忘了时间——忘了自己是在看水，还是在看招。
3. **顿悟** — 一道明悟落进心里。你站起身，浑身湿透，却觉得通体轻快。

#### 关联

- **地点**：漱玉峰（`docs/town-settings.md`）
- **奖励池**：4AP/5AP 招式（含 `unarmed`/`slash`/`pierce`/`polearm`/`blunt` 等系，随玩家武器 tags 过滤）

### 8. 回忆中的回忆

| 字段         | 内容                                              |
| :----------- | :------------------------------------------------ |
| **事件 ID**  | `memory_within_memory`                            |
| **地点**     | 旧回忆（第一阶段靠后位置，普通三选一池事件）        |
| **节点数**   | 1                                                 |
| **奖励类型** | 被动（passive）— 固有功法三选一                   |

#### 背景

第一阶段（旧回忆）靠后位置，你**忽然想起一段被遗忘的身世**——不是梦，是你自己的事。有些记忆被压在底下太久，某天被风一吹，自己浮了上来。

> 与主线"轮回/旧痕迹"呼应：你能想起来的这些身世，可能也和某一轮旧时光有关。

#### 流程

1. **旧忆** — 你坐在树下歇脚，风一吹，脑子里忽然浮起一段小时候的事。
2. **身世** — 你顺着那段记忆往下想。有些事不是别人，就是你自己。
3. **记起** — 你记起自己的身世，三选一：
    - **独臂**（`one_arm`）— 你想起那年青山边缘的狼群。你五岁被拖进林子，命捡回来了，左手没了。从那时起只用一只手练武。招式消耗降低 1AP（最低 1），无法双持
    - **药屋旁支**（`ningqi_jue`）— 你家分支早已搬出主宅，但血脉没断——凝炁诀代代相传。所有招式带炁，全属性 +1（**玄门故事不出现**，`Choice.when` 门控）
    - **周家后人**（`zoldyck_art`）— 你身上流的血，和奇岚一样，天生亲近雷电。周氏秘法，免疫麻痹并减免雷系伤害

> 注：这三段都是**实打实的身世**（药屋/周氏是血脉，独臂是年少断臂），不是借来的梦。固有功法（`inherent` 标签）通常被排除出普通奖励池，仅通过本事件获得。

#### 关联

- **触发**：第一阶段靠后节点（n12-21）的**普通三选一池候选**（`fallback`，非必出）；每局至多一次（`memory_done` 门控）
- **奖励**：固有被动三选一（`one_arm` / `ningqi_jue` / `zoldyck_art`，`Choice.when` 支持按故事排除选项）

| **地点**     | 图书馆 / 天工坊（池事件，每局至多一次）|

- **图书馆打工**（`library_job`）— 帮龙语仙把武学残卷按谱系分类整理：把所有书的摘要都看过、整理过，**天下武学的路数入了脑** → 活武学宝典（`martial_arts_archive`，不是一本书，是整理过程中记住的武学知识）
- **天工坊打工**（`tiangong_job`）— 帮千星拉风箱打铁 → 千星的锻体指点 **千锤百炼**（`qian_chui_bai_lian`）

> 注：这两个固有功法被排除出普通奖励池，仅通过打工事件获得（`library_job_done` / `tiangong_job_done` 门控，每局至多一次）。活武学宝典已从药屋小花的固定奖励中移除。

## 斗炁大会流程与胜负结算

| 节点 | 事件 | 内容 |
| :--- | :--- | :--- |
| n23 | 开幕 | 小组赛第一轮 |
| n26/27/28 | 小组赛 | 后两轮 → n28 出线结算（定十六强名单，无战斗） |
| n29/30/31 | 淘汰赛 | 十六强 / 八强 / 四强（无奖励） |
| n33 | 决赛 | 打完定冠军（无奖励） |

- **真实战斗结果会写回赛程**：玩家每场胜负决定晋级/出线；夺冠时 `championId = 玩家`，正常走完 33 节点结束。
- **淘汰 → game over**：小组赛未出线（n28 判）、淘汰赛输一场（下一节点判）、决赛落败（战斗后判）。
- **受伤满 100 → game over**：每输一场 +20 伤势，节点推进时伤势 ≥100 即提前结束。
- 默认 Boss：一阶段 Boss / 守门人（n22）未指定敌人时，**随机挑一个对手**；故事线可用 override 覆盖指定。

## 奖励预算表

| 项 | 数量 |
| :--- | :--- |
| 修炼点（+4/次） | **16 次** |
| 其他奖励（招式/功法/奇物/武器） | **13 个** |
| 无奖励节点（淘汰赛 4 场） | 4 个 |

> 说明：
> - 29 = 33 − 4，含 n1 的开局奖励（各线开局奖励：天生道种=奇物"天生道种"，其余 4 线=修炼点）。
> - 所有非淘汰赛节点都发放奖励（剧情场景节点也带奖励轮）。
> - n2/n3 必为实体奖励（选武器/选招式）；回忆事件为固定功法三选一，同样计入实体奖励。
> - 修炼点为**动态配额**：按「还需的修炼点 ÷ 剩余机会数」决定本轮是否出修炼点——差得远就多出现，给多了就少出现；快来不及达到 16 次时**强制给修炼点**（不再给 3 选 1）；打满 16 次后不再出现修炼点选项（选赤手空拳的 +4 也计入这 16 次）。
> - 天生道种的奇物"天生道种"效果为 **8 点修炼**（每 3 节点 +1，共 8 次），是奇物自带效果，**不计入**上表的 16 次预算。
> - 医馆疗伤计在"其他奖励"槽位内。
> - 固定奖励事件（如回忆事件）不消耗修炼点配额；后续新增固定奖励事件时需同步在 `countRewardOpportunities` 中排除。
> - 当前角色/招式/功法池数量尚不足以填满全部奖励槽，后续随角色补完逐步补齐。
