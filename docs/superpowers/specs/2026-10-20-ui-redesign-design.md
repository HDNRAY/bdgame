# UI 改版设计：克制的像素界面（移动与桌面双布局）

## 背景

现状不是「没有设计」，是「设计只做了一半」：

- 全站 104 条 `border`、10 条 `box-shadow`、8 条 `gradient`，45 个 SCSS 文件；边框承担了几乎所有分隔。
- 没有 Panel / SectionHeader / Stat 这类原语，每个面板各写一套表面与标题。
- 1280 下大量空白（首页 / 开场 / 构筑），320 下战斗页右侧被裁、标题截断、提示层盖住半屏。
- 颜色系统本身是完整的（语义 token、双主题、对比度测试、54 个标签色），缺的是使用方式与原语层。

参考：Refactoring UI（Wathan & Schoger）及 [refactoring-ui-skill](https://github.com/s0xDk/refactoring-ui-skill)（MIT）。只取原则，不引入 Tailwind 或任何运行时依赖。

## 目标

- 保留极简与像素身份，把「空」变成「有层次」。
- **移动与桌面同等重要**，允许两套布局：不把桌面压进 320，也不把手机拉伸到 1280。
- 不新增字体、不重做色相、不做全站美术重绘。
- **不改页面文案、不新增数据**：UI 改版只动视觉与布局，文案保持原样。

## 设计原则

1. 层次靠字重、颜色、间距；字号受像素网格限制（10 / 12 / 24 / 36 / 60）。
2. Surface 阶梯 + 零模糊硬阴影；边框只留给控件。
3. 每屏一个主行动；accent 只给可操作与焦点。
4. 组间距 > 组内间距；每加一个装饰，必须换来一个层次。
5. 双端各自构图，断点只留 768 / 1024。

## 设计系统

### Surface 阶梯（两个表面角色 + 一条细分隔线）

| 角色 | 亮 | 暗 | 用途 |
| --- | --- | --- | --- |
| `--color-surface-panel` | `#f2f2f5` | `#18181b` | 面板 / 侧栏 / 首页框 |
| `--color-surface-raised` | `#ffffff` | `#242428` | 浮起：卡片、弹层、焦点区 |
| `--color-border-subtle` | `color-mix(border 45%, bg)` | `color-mix(border 55%, bg)` | 面板内分隔线（非控件） |

- 面板默认**不描边**：用 surface + 硬阴影 + 间距分隔。
- 边框只保留给可交互控件（按钮、输入、标签页）；分隔线用 `--border-subtle`（低对比）。
- 初值在实现时用两套主题的对比度测试校准，不直接写死到组件里。

### 高度（零模糊硬阴影）

| 角色 | 亮 | 暗 | 用途 |
| --- | --- | --- | --- |
| `--shadow-raised` | `2px 2px 0 rgba(0,0,0,.12)` | `2px 2px 0 rgba(0,0,0,.6)` + `inset 0 1px 0 rgba(255,255,255,.06)` | 卡片、主按钮 |
| `--shadow-pressed` | `inset 1px 1px 0 rgba(0,0,0,.18)` | `inset 1px 1px 0 rgba(0,0,0,.5)` | 按下 |
| `--shadow-overlay` | `4px 4px 0 rgba(0,0,0,.18)` | `4px 4px 0 rgba(0,0,0,.65)` | 弹层、tooltip |

- 按下时阴影收掉 + `translate(1px, 1px)`，不做模糊。
- 像素风格只认硬边，不引入 `blur` / `backdrop-filter`。

### 文字角色

| 角色 | 字号 / 字重 | 颜色 | 用途 |
| --- | --- | --- | --- |
| display | 36 / 700 | text-h | 首页、章页 |
| title | 24 / 700 | text-h | 面板标题、区块标题 |
| value | 24 / 700 | text-h | 属性值、伤害数字 |
| body | 12 / 400 | text | 正文 |
| label | 12 / 400 | text-dim + 字距 `.05em` | 字段名、表头、眉标 |
| micro | 10 / 400（仅移动端） | text-dim | 角标、脚注 |

- 桌面最小 12px，所以不要靠「更小」压层次；用 dim、字距、间距、字重。
- 正文行高 1.7，标题 1.2；数字右对齐（表内）。

### 间距与布局

- 沿用 4 / 8 / 12 / 16 / 24 / 32，新增 48 / 64 两个页面级档位。
- 圆角统一：控件 2px，面板 4px；不再用 8px。
- 桌面内容最大宽度 1200px，12 栅格、24px 沟槽；侧栏固定宽，主区弹性。
- 移动单列、12px 边距；所有可点区 ≥44×44。
- 768–1023 用桌面两栏但收窄（侧栏变窄、沟槽 16px），不单独造第三套构图。

### 品牌细节（少量、可复用）

- 首页 / 章页的框用 1px 低对比描边 + 对角像素刻线（两条 8px L 形）。
- 页面底可加 3% 网格 / 点阵纹理；只在背景，不盖内容。
- 面板标题左侧 2px accent 竖条，作为「当前区块」的标记。

## 原语

| 原语 | 职责 | 关键约束 |
| --- | --- | --- |
| `Panel` | surface / 高度 / 内边距 / 可选标题与操作区 | 默认无边框；`raised` 变体用 surface-2 + `--shadow-raised` |
| `SectionHeader` | label + title + 右侧操作 | 组间距 > 组内间距；标题 24，label 12 dim |
| `StatBar` | 标签 + 数值 + 分段条 | 分段的像素刻度；数值右对齐；tooltip 走现有组件 |
| `Tabs` | 移动端面板切换 | 触屏命中 ≥44；当前项 accent 竖条 + accent-bg |
| `EmptyState` | 空状态 | 一行标题 + 一句说明 + 一个动作；不写「暂无数据」四个字了事 |

现有 Button / Tag / Tooltip / Modal 保留，只补高度与主次用法，不重写契约。

## 页面布局

### 首页

- **移动 320–767**：单列居中。外层框（`--color-surface-panel` + 硬阴影 + 对角刻线）内放标题、题记、主按钮；背景点阵。按钮上方留白略大于下方。
- **桌面 ≥1024**：两栏。左栏是标题 + 主按钮；右栏只放现有题记，**不加任何新文案或数据**。两栏共用同一套框，不做拉伸式留白。

### 构筑

- **移动**：单列，分组为「角色 / 招式 / 属性 / 功法 / 奇物」；默认展开前两组，其余折叠；步进器 44×44；招式行改为「名称 + 条件」两行，不再三列硬塞；底部固定操作条（在常驻底栏之上）放「返回 / 保存」。
- **桌面**：最大 1200，两栏：左 58%（角色 + 招式 + 触发），右 42%（属性 + 功法 + 奇物）。标题用 SectionHeader，数值 24/700，标签 12 dim；保存留在页首右侧。

### 战斗

- **移动**：战场置顶、固定比例（约 3:2）；下面依次是名字 / 气血 / 内息；两侧面板收成下方三个标签页「战况 / 招式 / 日志」，一次只看一个；日志默认收起；标题换行，不省略。
- **桌面**：三栏（左右各 280px，中间弹性）；战场抬为 surface-2，两侧面板压为 surface-1；日志在中间下方，限高可滚；主动作在役。

## 断点与验收

- 绘制与验收档位：320×568、390×844、768×1024、1280×800、1440×900；亮 / 暗两套主题。
- 硬口径：`scrollWidth == innerWidth`；移动端可点区 ≥44×44；不依赖 hover；字号在网格；文本对比 ≥4.5。
- 触屏交互：tooltip 点开、点外关闭；不用 hover 才能看到的信息（战斗页现有的悬停提示层要改）。
- 新增两条检查：
  1. `overflow: hidden` 容器内 `scrollWidth > clientWidth + 1` 且含文字 → 报警（当前战斗页就是这类漏网）。
  2. 移动端主要页面的可点元素逐个量命中区（不只底栏）。
- 改颜色跑 `scripts/scss-triples.mjs` 与 `scripts/ui-computed-style.mjs`；几何跑 `scripts/ui-geometry.mjs`；截图双端目视。

## 分阶段

0. 系统层：surface / 阴影 / 文字角色 / 间距 / 原语 + 文档。
1. 首页：移动与桌面两版，作为视觉样板。
2. 构筑：两版。
3. 战斗：两版。
4. 其余页面（斗炁大会 / 图鉴 / 设置 / 关于）按同一套原语铺开。

## 不做

- 不引入 Tailwind；不换字体；不重做整套色相；不加 emoji。
- 不改页面文案、不加新数据（UI 改版只动视觉）。
- 不做全站美术重绘（贴图、立绘、复杂动效）；不一次性重写 45 个 SCSS。
- 不为了「看起来丰富」加无意义的装饰；每个装饰必须对应一个层次。
